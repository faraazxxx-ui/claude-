The limit, stated first

My reasoning text is not in this export

Not redacted here — never written. All 60 reasoning blocks were stored signature-only.

What survives for each reasoning block: that it happened, where in the conversation, its signature hash and length, and roughly how many tokens it consumed. What does not: a single character of what it said. No amount of re-processing the transcript changes this — the plaintext was never on disk.

Anyone reconstructing “the model’s thinking” from this data is reconstructing its shape and cost, not its content. A claim otherwise is false, and this export gives you the means to check it: SELECT * FROM blocks WHERE kind='thinking' returns 60 rows with chars = 0 and redacted = 1.

Derivations · check these before trusting any number

Two figures are estimates

hidden_tokens_est = output_tokens − (visible_chars ÷ 4)

  output_tokens   exact, billed. Covers reasoning + reply + tool arguments.
  visible_chars   exact. Everything actually emitted.
  ÷ 4             the standard chars-per-token approximation.
                  NOT a measurement. The only soft term in the calculation.

shown_fraction    = visible tokens ÷ (visible + hidden). Inherits the same
                    approximation.
Everything else is exact — character counts, block counts, tool counts, timestamps, SHA-256 checksums. If you have a real tokeniser, substitute it for the ÷ 4 and both estimates improve. The builder is included so you can.
Structure

Seven tables, four views

turns → blocks is the spine; everything else hangs off it.

session ──┬── turns ──┬── blocks ──── tool_calls   (joined on tool_use_id)
          │          └── usage
          ├── exchanges     one message he typed + everything it caused
          └── artifacts     files produced, with SHA-256

block      one content unit: text | thinking | tool_use | tool_result | plain
turn       one logical message. Records sharing a message id are grouped —
           without that, usage counts once per block instead of per response
           and every derived figure inflates.
exchange   the unit of "his thinking vs mine"
-- The finding this export exists to show
SELECT exchange_no, ask_chars, hidden_tokens_est, reply_chars, shown_fraction
FROM   v_his_vs_mine
ORDER  BY hidden_tokens_per_ask_token DESC;

-- Prove the reasoning is unrecoverable rather than taking my word
SELECT COUNT(*), SUM(chars), SUM(redacted) FROM blocks WHERE kind='thinking';
