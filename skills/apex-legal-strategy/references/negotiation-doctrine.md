# Negotiation Doctrine — zero-sum posture, honestly run

Full living documents: `legal-war-room/strategy/damages-architecture.md`,
`legal-war-room/mediation/mediation-execution-plan.md`. This file is the durable method.

## The stance

Litigation-settlement negotiation is distributive: their dollar is our dollar. Play it hard — but the
instrument of force is **legitimate pressure** (comprehensive discovery, multi-front verified claims,
fee-shifting accrual, spoliation exposure), never bluff or fabrication. One overreach a competent
opponent can call kills the anchor and reprices everything downward.

## Anchoring, done right

- **Anchor** = exposure ceiling (~$100M tier): the runaway-jury scenario with its assumptions listed.
  It enters through the *defense-counsel exposure conversation*, not the mediator's opening, always with
  its ASSERTED/POSTURE label and the caveat script. It reframes the ZOPA; it is never pled or certified.
- **Acceptance threshold** ($40M, client directive) sits far above the defensible trial range
  ($4.34M–$16.57M verified arithmetic) — counsel must own that gap with the client BEFORE mediation,
  or the mediator will own it during.
- **Floor/BATNA** = documented core ($1.22M–$1.60M) + the non-monetary must-haves + the trial path
  (fee-shifting accrues monthly; §1983 rail alive to ~2028).

## The concession ladder

Each rung trades something we can afford for something they can't easily refuse; never concede without a
return. Non-monetary demands go FIRST (record correction, neutral reference, licensure/USCIS support
letter): cheap for defendants, priceless for the client — they create momentum and goodwill asymmetry
before dollars are discussed.

## Counter-instinct rule (the user's "find the counter" doctrine)

When an obstacle appears — a limitations problem, an immunity, an adverse case — the reflex is:
1. best counter, 2. fallback counter, 3. residual-risk grade. Only then decide whether to concede ground.
Obstacles and their counters live in `obstacle-counter-matrix.md`; hiding an obstacle from the matrix is
a review failure. Pattern instances: SoL Rail A blocked → Rail B §1983 (*Dennis v. Sparks* joint action);
notice-of-claim trap → *Felder v. Casey* (no notice requirement on §1983); *Cummings/Barnes* strip Title VI
damages → NYSHRL amendment restores uncapped distress + punitives.

## Pressure architecture ("death by a thousand cuts", ethically bounded)

Volume pressure is legitimate only when every request is genuinely relevant: the discovery program
(academic record, ANSCO CCTV, Nadeem texts, Guthrie call/poster file, DA file, HR complaints) is broad
BECAUSE the instigation web is broad. Sequence so each production feeds the next demand and each
contradiction (Ahmed's authority denial, AF6/AF8, the 24-hour reversal) compounds. Track per-defendant
fear in `legal-war-room/strategy/pressure-point-map.md`.

## Projection discipline

"Victory continuously projected" = the maintained win-probability document with named update triggers —
bands move on evidence, not on morale. The composite (≥1 significant claim trial-ready ≈ 80–90%) is the
number that prices mediation, not any single claim's ceiling.
