# Outpatient Order Set — Suspected Type 1 (Distal) RTA with Nephrolithiasis and Persistent Hematuria

**Use:** Physician order template. Adapt to local formulary and lab compendium.
**Billing codes deliberately omitted.** CPT/LOINC codes vary by lab and payer, and a wrong code causes a denied claim or a mis-collected specimen. Map test names to your compendium at order entry.
**De-identified.** No patient identifiers in this file.

## PRIORITY 0 — Do these before anything else (same visit, no cost)

| ☐ | Action | Why |
|---|---|---|
| ☐ | **Resolve the imaging ambiguity: is the calculus obstructing or non-obstructing?** | An obstructing stone *with infection* is a **urologic emergency** requiring same-day decompression. Everything below assumes non-obstructing. |
| ☐ | **Correct the stone size in the record** ("0.2 mm" is below CT resolution — presumed 2 mm / 0.2 cm) | Accuracy of the record |
| ☐ | **Full medication reconciliation** — explicitly ask about **topiramate, acetazolamide, zonisamide, lithium, amphotericin B, ifosfamide, SGLT2 inhibitors, NSAIDs, TMP-SMX, ACEi/ARB** | Drug-induced RTA is a **perfect phenocopy and fully reversible.** Cheapest possible diagnosis. |

| ☐ | **Document gross vs microscopic hematuria** | Determines which hematuria pathway applies |

## SECTION A — Confirm and characterize the acidosis

> **Draw blood and urine at the same sitting, first-morning void, patient not acutely ill, off antibiotics, with a concurrent culture proving sterility.**

### A1 — Blood

| ☐ | Test | Note |
|---|---|---|
| ☐ | **Venous blood gas** (pH, pCO₂, HCO₃⁻) | **Mandatory.** Without a pH you have not proven acidosis vs. compensation for chronic respiratory alkalosis. |
| ☐ | Comprehensive metabolic panel | Na, **K**, **Cl**, CO₂, BUN, Cr, glucose, Ca, **albumin**, LFTs |
| ☐ | **Serum potassium — flag as priority** | Low → Type 1. High → Type 4, reformulate. |
| ☐ | Serum magnesium, phosphorus | Fanconi screen; refeeding risk |
| ☐ | Serum uric acid | Low → proximal tubulopathy |
| ☐ | Intact PTH | Stone panel; distinguishes primary hyperparathyroidism |
| ☐ | 25-OH vitamin D; 1,25-OH₂ vitamin D | Bone disease; sarcoid |
| ☐ | Alkaline phosphatase | Osteomalacia |
| ☐ | CBC with differential | Anemia, infection |
| ☐ | HbA1c | Ketone differential; Type 4 risk |
| ☐ | **β-hCG** | **Required before CT** |
| ☐ | eGFR (CKD-EPI) | Baseline |

**Calculate and record:**
- Serum anion gap = Na − (Cl + HCO₃)
- **Albumin-corrected AG = measured AG + 2.5 × (4.0 − albumin g/dL)**
- Delta-delta if any suggestion of a mixed disorder

### A2 — Urine, same specimen

| ☐ | Test | Note |
|---|---|---|
| ☐ | **Urine pH by pH meter or blood-gas analyzer** — NOT dipstick | **Dipstick (±0.5 pH) is inadequate to diagnose RTA.** Fresh, capped, no preservative, analyzed immediately. |
| ☐ | **Urine osmolality** | For the osmolal gap |
| ☐ | **Urine sodium, potassium, chloride** | For the osmolal gap and to confirm U_Na >25 mEq/L |
| ☐ | **Urine urea nitrogen, urine glucose** | For the osmolal gap |
| ☐ | Urine creatinine | Normalization |
| ☐ | **Urinalysis with microscopy** | Glycosuria with normal serum glucose → proximal tubulopathy |
| ☐ | **Phase-contrast microscopy of fresh spun sediment — dysmorphic RBCs, acanthocytes, RBC casts** | **The glomerular / non-glomerular fork. Do not skip.** |
| ☐ | **Urine culture — test of cure**, plus request extended incubation for ***Corynebacterium urealyticum***; consider ***Ureaplasma*** if urine remains alkaline and "sterile" | Routine culture misses both |
| ☐ | Urine protein/creatinine ratio and albumin/creatinine ratio | Glomerular screen |

**Compute — and use this instead of the urine anion gap:**

> **Urine osmolal gap** = measured U_osm − [2(U_Na + U_K) + U_urea/2.8 + U_glucose/18]
> **Estimated urine NH₄⁺ ≈ gap ÷ 2**
> **>75 mEq/L** = appropriate response (extrarenal/GI cause) · **<25 mEq/L** = renal acidification defect
>
> **The urine anion gap is INVALID in this patient** — her ketoanions are unmeasured urinary anions that make the UAG falsely positive and counterfeit the dRTA signature.

### A3 — Provocative testing

☐ **NOT indicated.** Furosemide/fludrocortisone and NH₄Cl loading exist to unmask *incomplete* dRTA in patients with a **normal** serum bicarbonate. She has **spontaneous** acidosis with alkaline urine — complete dRTA. Do not acid-load an acidemic patient. Reserve only if the repeat clean bicarbonate normalizes.

## SECTION B — Autoimmune and secondary-cause panel ★ *as requested*

> **Rationale:** Sjögren's syndrome is the commonest acquired cause of distal RTA in adult women. Panel is sequenced tier-1 first; tier 2 only if tier 1 is positive or clinical suspicion persists.

### B1 — Tier 1 (order now)

| ☐ | Test | Target |
|---|---|---|
| ☐ | **ANA with titre and pattern** (IFA on HEp-2) | SLE, Sjögren's, systemic autoimmunity |
| ☐ | **Anti-Ro / SSA** | **Sjögren's — highest yield in this phenotype** |
| ☐ | **Anti-La / SSB** | Sjögren's |
| ☐ | **Rheumatoid factor** | Sjögren's (often positive), RA |
| ☐ | **Quantitative immunoglobulins (IgG, IgA, IgM)** | **Polyclonal hypergammaglobulinemia is characteristic of Sjögren's-associated dRTA** |
| ☐ | **SPEP with immunofixation + serum free light chains (κ/λ)** | **Excludes plasma cell dyscrasia — a cause of acquired Fanconi/dRTA that must not be missed** |
| ☐ | **UPEP with immunofixation** | Light chain disease |
| ☐ | Complement C3, C4 | SLE, immune complex disease |
| ☐ | ESR, CRP | Inflammatory burden |
| ☐ | TSH, anti-TPO | Autoimmune thyroiditis (frequent co-travel) |
| ☐ | **Hemoglobin electrophoresis / sickle solubility** | **Sickle cell trait — hematuria via papillary necrosis + impaired acidification** |
| ☐ | Hepatitis B surface antigen, hepatitis C antibody, HIV | Secondary causes; pre-immunosuppression baseline |

### B2 — Tier 2 (if tier 1 positive, or clinical suspicion persists)

| ☐ | Test | Target |
|---|---|---|
| ☐ | Anti-dsDNA, anti-Smith | SLE |
| ☐ | Anti-CCP | RA |
| ☐ | **AMA (anti-mitochondrial antibody)** | **Primary biliary cholangitis — a recognized dRTA association** |
| ☐ | ASMA, anti-LKM | Autoimmune hepatitis |
| ☐ | **Serum IgG4 subclass** | IgG4-related tubulointerstitial nephritis |
| ☐ | **ACE level; ionized calcium; 1,25-OH₂ vitamin D** | Sarcoidosis |
| ☐ | ANCA (PR3, MPO) | Vasculitis if glomerular hematuria |
| ☐ | Anti-GBM | If RPGN picture |
| ☐ | Tissue transglutaminase IgA + total IgA | Celiac (associated) |
| ☐ | **Brucella serology** | **If unpasteurized dairy plus fever, night sweats, or persistent back pain** |

### B3 — Sjögren's functional and structural assessment

| ☐ | Study |
|---|---|
| ☐ | **Schirmer test** (± ocular staining score — refer Ophthalmology) |
| ☐ | Unstimulated whole salivary flow rate |
| ☐ | **Salivary gland ultrasound** |
| ☐ | **Minor labial salivary gland biopsy** — only if serology negative and suspicion remains high (Rheumatology to direct) |

## SECTION C — 24-hour urine stone panel ★ *as requested*

> **Collect TWO separate 24-hour collections** on her **usual, unrestricted diet**, on **separate non-consecutive days**, at least **4 weeks after** the acute infection and off antibiotics. Confirm adequacy by creatinine (♀ ≈ 15–20 mg/kg/day, ♂ ≈ 18–24). An under-collected specimen is worse than none — it reads as falsely reassuring.

| ☐ | Analyte | Reference / target |
|---|---|---|
| ☐ | **Total volume** | **Target >2.5 L/day** |
| ☐ | **Creatinine** | Adequacy check — validates the whole collection |
| ☐ | **Calcium** | Hypercalciuria: >250 mg/day ♀, >300 ♂ (or >4 mg/kg) |
| ☐ | **Citrate** | **Hypocitraturia <320 mg/day — expect markedly low in dRTA; the key therapeutic target** |
| ☐ | **Oxalate** | >40–45 mg/day abnormal |
| ☐ | **Uric acid** | >750 mg/day ♀, >800 ♂ |
| ☐ | **pH** (24-h aggregate) | **Persistently >6.0–6.5 → calcium phosphate risk** |
| ☐ | **Sodium** | Surrogate for salt intake; drives hypercalciuria. Target <100 mEq/day |
| ☐ | **Potassium** | Intake and renal wasting |
| ☐ | **Magnesium** | Inhibitor |
| ☐ | **Phosphorus** | CaP stone risk |
| ☐ | **Sulfate** | **Surrogate for animal protein load — directly relevant to her cheese/whey intake** |
| ☐ | **Urea nitrogen (PCR / protein catabolic rate)** | Dietary protein quantification |
| ☐ | **Ammonium** | **Low in dRTA — a direct measure of the acidification defect** |
| ☐ | **Cystine** (screening, at least once) | Excludes cystinuria |
| ☐ | **Supersaturation indices — calcium oxalate, calcium phosphate (brushite), uric acid** | **Drives therapy and is the metric to re-titrate against** |

**Companion order:**

| ☐ | **STONE COMPOSITION ANALYSIS** (infrared spectroscopy or X-ray diffraction) on any calculus retrieved or passed | **Apatite/calcium phosphate → confirms dRTA. Struvite → the Klebsiella was the driver. This single result can redirect the entire workup.** |

## SECTION D — Imaging

| ☐ | Study | Indication |
|---|---|---|
| ☐ | **Non-contrast CT abdomen/pelvis (renal stone protocol), thin slices** | Stone burden; **medullary nephrocalcinosis**; assess for **medullary sponge kidney** — the leading unifying hypothesis. Confirm β-hCG negative first. |
| ☐ | **CT urography** (unless contraindicated) | Upper-tract evaluation for persistent hematuria; **papillary ductal ectasia / "bouquet of flowers" pattern of MSK** |
| ☐ | Renal and bladder ultrasound | If contrast or radiation is contraindicated; also the 2025 AUA/SUFU intermediate-risk pathway |
| ☐ | **DEXA (bone densitometry)** | **Chronic dRTA causes osteomalacia and osteopenia — routinely omitted and should not be** |
| ☐ | Renal vein Doppler / CT venous phase | Only if nutcracker syndrome is suspected (left flank pain, slender habitus) |

## SECTION E — Hematuria pathway

**Fork on the phase-contrast microscopy result:**

| Finding | Pathway |
|---|---|
| **Dysmorphic RBCs, acanthocytes, RBC casts, or proteinuria** | **Glomerular.** → Nephrology priority; consider IgA nephropathy, thin basement membrane, Alport, lupus nephritis. Urine protein quantification, complements, ANCA/anti-GBM if rapidly progressive. **Renal biopsy per Nephrology.** |
| **Isomorphic RBCs, no casts, no proteinuria** | **Non-glomerular.** → **Urology referral for cystoscopy + upper-tract imaging.** |

| ☐ | Order | Note |
|---|---|---|
| ☐ | **Urology referral** | **If gross (visible) hematuria: full evaluation — cystoscopy plus CT urography — regardless of risk category.** If microscopic: apply the **2025 AUA/SUFU microhematuria risk stratification**; intermediate risk → cystoscopy + renal ultrasound. |
| ☐ | Urine cytology | Not a screening test; per Urology, and useful in the 2025 pathway for counselled intermediate-risk patients declining cystoscopy |
| ☐ | Coagulation studies (PT/INR, aPTT) | If anticoagulated or bleeding history |

## SECTION F — Empiric management to start now (pending confirmation)

| ☐ | Intervention | Detail |
|---|---|---|
| ☐ | **Fluid** | **Target urine output >2.5 L/day** — spread across the day and including a bedtime intake |
| ☐ | **Potassium citrate** — start once potassium and renal function are known | **Potassium salt, NOT sodium bicarbonate or sodium citrate** — sodium salts raise urinary calcium. Typical adult start 10–20 mEq PO TID (≈1–2 mEq/kg/day divided). |
| ☐ | **Titrate to serum HCO₃⁻ 22–24 AND urinary citrate >320 mg/day — not to urine pH** | **Her urine is already alkaline; over-alkalinizing worsens calcium phosphate supersaturation.** Keep urine pH ≈6.5–7.0 and re-check CaP supersaturation on the follow-up 24-hour urine. |
| ☐ | Recheck BMP 1–2 weeks after starting or changing alkali | Hyperkalemia and bicarbonate response |
| ☐ | Dietary counselling | **Sodium <2,300 mg/day. Moderate animal protein (0.8–1.0 g/kg/day). CONTINUE dietary calcium 1,000–1,200 mg/day *taken with meals*. Avoid calcium supplements between meals. Ensure milk/cheese is pasteurized.** |
| ☐ | Thiazide — only if hypercalciuria persists on the repeat 24-h urine | **Compounds hypokalemia in dRTA** — pair with potassium citrate, consider amiloride |
| ☐ | Analgesia | Avoid chronic NSAIDs — nephrotoxic and can worsen a Type 4 picture |

## SECTION G — Referrals

| ☐ | Service | Urgency | Rationale |
|---|---|---|---|
| ☐ | **Nephrology** | **Routine-urgent, ≤2–4 weeks** | Confirm and manage RTA; direct biopsy if glomerular |
| ☐ | **Urology** | **Routine-urgent, in parallel — do not serialize** | Persistent hematuria; stone management. Nephrology will not perform cystoscopy. |
| ☐ | Rheumatology | After tier-1 serology returns | Sjögren's or other systemic autoimmune disease |
| ☐ | Registered dietitian (stone-specific) | Routine | Sodium, protein, calcium-timing counselling |
| ☐ | Ophthalmology | If sicca symptoms | Schirmer / ocular staining score |
| ☐ | Audiology | If hearing symptoms or suspected inherited dRTA | *ATP6V1B1*-associated sensorineural hearing loss |

**Escalate to same-day evaluation if:** K⁺ <3.0 mmol/L · HCO₃⁻ <15 mmol/L · symptomatic weakness, paralysis, or arrhythmia · rising creatinine · fever with an obstructing stone · sepsis.
