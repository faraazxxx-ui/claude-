Intervention · one hour, in order

Setup

  1. Find the model you already downloaded

    Use whatever tag this prints — don't guess it.

    ollama list
    Not there?

    Pull it: ollama pull gemma4. Ollama's own Hermes guide recommends Gemma 4 as the local model on a Mac with ~16GB.

  2. Give it a real context window

    Ollama's default is tiny. This is the single biggest reason local agents feel stupid.

    OLLAMA_CONTEXT_LENGTH=64000 ollama serve
    Confirm it took

    Run ollama ps — the CONTEXT column should read 64000. If it says 4096, the variable didn't reach the server process.

  3. Install Hermes

    You already have Ollama, so this one line wires both together.

    ollama launch hermes

  4. Give it two brains

    The money decision. A smart brain for thinking, a local brain for grunt work and anything private.

    hermes model
    What to pick at each prompt

    Main model → Claude Opus. This plans, reasons, drafts.

    Local model → choose Custom endpoint, URL http://127.0.0.1:11434/v1, leave the API key blank, then pick your gemma4 tag. There is no "Ollama" option — custom endpoint is the way in.

    Then run hermes doctor. It checks exactly this.

  5. Put it in a box

    Hermes runs terminal commands on your Mac by itself. See the next section before you skip this.

    hermes config set terminal.backend docker

  6. One channel, then five sentences

    Pick WhatsApp — you already live there. Allow your own number only.

    hermes gateway setup && hermes gateway install

    Then send it these. No cron syntax — you just tell it.

    • weekday 6amSend me a brief. Calendar, the three things that actually matter, anything that broke overnight. One short message.
    • daily 9pmFile everything I sent you today. Don't ask me where things go — decide, then tell me in one line what you did.
    • sunday 8pmWeek ahead, plus what I said I'd do this week and didn't. Be blunt about the second part.
    • weekday 7amCheck the docket for 3:26-cv-00197. Flag any deadline inside 14 days.
    • nightlyPull my health data, give me a three-line trend. Local model only — this does not leave my Mac.

Read this one

Your Mac holds PHI and an active federal case

Hermes executes terminal commands on that machine on its own initiative. Docker gives it a sandbox to do that inside. Command approvals are the second layer.

hermes config set memory.memory_enabled true

Keep command approvals on. Not "on for now" — on in month two, when they've become annoying. That is precisely the month you would regret turning them off.

Anything touching health records or case files routes to Gemma 4, which runs entirely on your machine. That data never crosses the network.

Prognosis

Month three is the test

Every system you've adopted has died around week three, when the novelty wore off. This one survives that week only because the schedule keeps running whether or not you engage.

If you catch yourself editing the routines more than using them, you've turned it back into a tool that needs discipline. Cut back to three and stop.

Hermes will not fix a messy operation. It will run your mess faster. Five routines is deliberately few — add a sixth only after you've felt its absence for a week.

The local model is not a free lunch. Gemma 4 is genuinely good at filing, tagging, and reading your health exports. It is not good enough to plan litigation strategy. Don't let cost-saving push real work onto the small brain.

Nine tools, one door. If any piece of this needs your daily discipline to survive, it's wrong — delete it.
