# Audioio

A local web toolkit that mirrors an iOS Audioio folder: generated isochronic tones, binaural beats, pink/white/brown noise, and rough maqām beds, plus day-part protocols for ADHD work, anhedonia/initiation, treatment-resistant depression shutdown, and burnout recovery.

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 4173 --directory audioio
```

Then visit `http://localhost:4173`.

This is an adjunct sound environment, not a treatment. Headphones are required for binaural sessions. Stop if mood darkens.
