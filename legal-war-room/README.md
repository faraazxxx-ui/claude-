## Canon rules

1. `data/*.json` is the single source of truth. Every dollar figure, date, and citation in any document must trace back here.
2. Damages figures carry evidence labels: **DOCUMENTED** (traceable to a record) / **ESTIMABLE** (method stated) / **ASSERTED** (posture — not for filings).
3. Case citations carry verification status: **VERIFIED** (retrieved from a court database) / **UNVERIFIED** (do not cite in filings).
4. `data/raw/` (verbatim transcript) is gitignored — it never leaves this machine.
5. Superseded older analyses are mapped in `RECONCILIATION.md`, never edited or deleted.
